这一页是后续所有 Lab 讲义的起点。复制它，替换正文，保留结构与 class 名。下面用真实的 HIP 话题演示每个组件长什么样、该在什么时候用。

预计阅读 15 分钟 · 对应 Assignment a1、a2

§1正文与行内元素

正文使用 Noto Sans SC，行宽约 38 个汉字，适合长时间阅读。行内代码写作 hipLaunchKernelGGL 或 threadIdx.x；需要着重的词用着重号而不是斜体；按键写作 Ctrl + C。

链接用硅片青色，例如 HIP 官方文档。

§1.1列表

  • 一个 wavefront 有 64 个 lane，同步执行同一条指令。
  • 一个 workgroup 最多 1024 个线程，即最多 16 个 wavefront。

§2代码块

C++ / HIP 代码用 language-cpp。注释里的 TODO(aK-n) 与“你的代码”标记会被自动标亮：

#include <hip/hip_runtime.h>

// 每个线程处理一个元素：c[i] = a[i] + b[i]
__global__ void vector_add(const float* a, const float* b, float* c, int n) {
    // TODO(a1-1): 计算全局线程编号 i（讲义 §2）
    // >>> 你的代码 <<<
    int i = blockIdx.x * blockDim.x + threadIdx.x;
    if (i < n) {
        c[i] = a[i] + b[i];
    }
}

int main() {
    constexpr int kBlock = 256;
    int n = 1 << 20;
    dim3 grid((n + kBlock - 1) / kBlock);
    vector_add<<<grid, kBlock>>>(d_a, d_b, d_c, n);
    return 0;
}

§3Callout

说明类：补充背景知识，不读也不影响主线。例如 HIP 的 blockDim 对应 CUDA 的同名变量。

注意类：容易误解但不至于出错的地方。例如 AMD 的 wavefront 是 64 lane，不是 CUDA 的 32。

常见坑：真的会让结果出错的地方。例如忘记边界检查 if (i < n)，当 n 不是 blockDim 的整数倍时会越界写。

用 data-title 可以自定义标题。
