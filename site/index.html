从 HIP 到 Mega Kernel

一门在 MI308X 上动手写 GPU kernel 的自学课程。从线程层级和访存讲起，经过 CK-Tile 与 MFMA tiled GEMM，再到多卡通信、通算融合，最后落到 mega kernel 技术。每个概念先在讲义里讲清楚，再用一个能自动判分的作业练一遍。

目标硬件：AMD MI308X（gfx942，80 CU，wavefront 64，LDS 64 KiB / block），ROCm 7.2

怎么学

每个 Lab 都按同一个节奏走。讲义里每节末尾的作业卡会告诉你：现在可以去做哪一题。

  1. 读讲义打开 Lab 的 tutorial.html，跟着图示和小部件把概念弄懂。
  2. 做作业在 aK-*/ 里补全 // TODO，卡住时按顺序看 README 里的 Hint。
  3. 判分在 Lab 目录运行 make grade，看正确性与性能用例是否全部通过。

课程目录

Lab 按顺序排列，后面的作业只用到前面讲过的概念。

  1. 0

    环境与工具

    ROCm 工具链与 hipcc、第一个 kernel、错误检查、查询设备属性，把判分流程走一遍。

    lab0-env打开讲义
  2. 1

    HIP 基础

    线程层级、全局访存与合并、LDS、并行归约、朴素与分块 GEMM。

    lab1-hip-basics打开讲义
  3. 2

    C++ 速成 + CK-Tile 入门

    读懂 CK-Tile 需要的模板、constexpr 与编译期序列，写第一个 CK-Tile kernel。

    lab2-cktile-intro打开讲义
  4. 3

    CK-Tile 核心概念

    layout 即坐标变换的组合，二维 tile distribution 与 LDS 转置，在 tile 上做行归约。

    lab3-cktile-concepts打开讲义
  5. 4

    MFMA 与 tiled GEMM即将推出

    用矩阵核心指令 MFMA 搭出分块 GEMM，理解寄存器里的数据排布。

  6. 5

    GEMM 进阶即将推出

    软件流水线隐藏访存延迟，并扩展到一次处理多个问题的 Grouped GEMM。

  7. 6

    多卡通信基础即将推出

    P2P 与 IPC 显存访问、RCCL 集合通信，以及 all-to-all 的实现方式。

  8. 7

    通算融合即将推出

    把 Grouped GEMM 与 all-to-all 放进同一条流水，让计算掩盖通信。

  9. 8

    Mega kernel 技术即将推出

    用一个常驻 kernel 调度多个阶段：任务队列、跨 block 同步与依赖管理。

讲义均为本地静态页面，直接用浏览器打开即可。作业判分在各 Lab 目录下运行 make grade；快速开始、判分规则与共享 GPU 说明见仓库根目录的 README.md。
